# Qt 6.11.0 embedded third-party license sources

These files are verbatim license texts from the official Qt 6.11.0 source
tags. They are kept in the repository so release checks work without Internet
access.

  - peeled commit: `4126867385dc0b7a9404dcd69726c28ed0d5e10a`

All per-file source paths and SHA-256 values are pinned in
`scripts/qt_runtime_manifest.json`. The release generator verifies every hash
before producing `QT_THIRD_PARTY_NOTICES.txt`.

This material supports attribution and release review. It is not legal advice,
and it does not choose a license for Aruba Mini Dashboard itself.
